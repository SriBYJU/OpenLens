# Research methodology

Device records use manufacturer product pages and developer documentation where available. Every claim carries a source ID, claim class, confidence, access date, and note.

OpenLens distinguishes manufacturer claims, OpenLens measurements, estimates, simulations, and unknown values. Missing specifications remain unknown. Field-of-view values preserve whether the source described a horizontal or diagonal angle.

Manufacturer documentation can establish that an SDK or companion path exists. It cannot establish that OpenLens has implemented or verified an adapter. Conflicting credible sources should be retained as separate claims with context rather than silently reconciled.

Corrections should increment the device revision, preserve the prior record in version control, explain the change, and update the access date. Hardware supplied by a manufacturer must be disclosed; contributions do not change methodology or conclusions.
