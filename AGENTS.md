# OpenLens Agent Guide

## Product north star
Build OpenLens as an open development, simulation, AI, research and benchmarking layer for smart glasses.

## Working method
INSPECT → PLAN → BUILD → RUN → LOOK → TEST → BREAK → FIX → REVIEW → VERIFY.

## UI rule
Rendered output is the truth. After significant visual changes, inspect desktop, mobile and tablet screenshots before sign-off.

## Efficiency
Use targeted navigation and diffs instead of repeatedly rereading the whole repository. Keep diagnostic detail on failures. Do not reduce context when security, architecture or correctness requires it.

## Trust
Never fabricate hardware support, measurements, AI calls, provider integration, sources or device connections.
